## Importante

- La sección "Perfil del desarrollador" es **pública** — la verán los usuarios en Play Store al tocar el nombre del desarrollador.
- **No es obligatoria al 100% para publicar en Internal Testing**, pero conviene completarla para que se vea profesional desde el inicio.
- Las **3 verificaciones** (identidad / sitio web / teléfono) **sí son obligatorias** — esas son las que viste con botones "Comenzar" / "Ver detalles". Las hacen el owner + tú (la del sitio web).
